# Azan Watch v2.1 — اذان واچ

## v2.1 میں کیا ٹھیک ہوا
- **اینڈرائیڈ APK**: پرانا TWA طریقہ ختم (اسے HTTPS سائٹ اور انٹرایکٹو سوالات چاہیے تھے، اس لیے بلڈ نہیں بنتا تھا)۔ اب **Capacitor** سے ایپ کی فائلیں APK کے اندر ہی بند ہوتی ہیں؛ سائٹ ہوسٹ کرنے کی ضرورت نہیں، انٹرنیٹ کے بغیر چلتی ہے۔
- APK میں مقام (GPS) کی اجازت، اسکرین آن رکھنا، اور اذان بغیر ٹچ کے بجنے کی ترتیب شامل۔ آئیکن خود بنتا ہے۔
- `build-android.yml` ورک فلو: ایک کلک سے `app-debug.apk` (عام موبائل پر انسٹال ہونے والی)۔
- v2.0 کی تمام اصلاحات برقرار (اذان ایک بار، حنفی عصر، آف لائن، اقامت، مسجد ڈسپلے وغیرہ)۔

## اینڈرائیڈ APK بنانا (GitHub)
1. تمام فائلیں (بشمول `.github` اور `scripts` اور `assets` فولڈر) ریپو میں push کریں۔
2. **Actions ← Build Android APK ← Run workflow**۔
3. سبز نشان آنے پر اسی رن کے صفحے کے آخر میں **Artifacts ← AzanWatch-APK** ڈاؤن لوڈ کریں۔ یہ zip ہوتی ہے؛ اسے extract کر کے `app-debug.apk` فون میں منتقل کریں۔
4. فون میں "نامعلوم ذرائع سے انسٹال" کی اجازت دے کر انسٹال کریں۔ پہلی بار کھولنے پر مقام کی اجازت دیں۔
   (صحیح APK کا سائز چند MB ہوتا ہے، 60+ MB نہیں۔)

اپنے کمپیوٹر پر (Android Studio/JDK 17 کے ساتھ): `npm install` ← `npm run android:prepare` ← `cd android` ← `gradlew assembleDebug`۔

## ڈیسک ٹاپ (Windows/Linux)
```
npm install
npm start            # چلانے کے لیے
npm run dist:win     # Windows installer + portable EXE
npm run dist:linux   # AppImage + deb
```
یا Actions ← *Build Desktop (Windows EXE / Linux AppImage)*۔ (یہ بڑے سائز کی فائلیں، تقریباً 60-100 MB، بناتا ہے، یہ موبائل کے لیے نہیں ہیں۔)

## ویب/PWA
تمام فائلیں HTTPS سرور (مثلاً GitHub Pages) پر رکھ کر `azan-watch.html` کھولیں۔
